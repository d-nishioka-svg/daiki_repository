# 導入手順

`Code.gs` を、学習進捗管理スプレッドシートに紐づけて使えるようにする手順です。2つの使い方があります。

- **A. メニューから手動で貼り付け(初回から使える、AI不要)** — Claudeが作った記録文をコピペするだけの方式
- **B. Webアプリ経由でVTTから自動作成(要: GeminiRaytechライブラリ、Web App配布設定)** — VTTファイルをアップロードすると、AIが要約案を作り、内容を確認してから書き込める方式。企業・受講者の新規登録や、集団相談用のグループ管理もこのWebアプリから行える。

Bはコードを追加しただけでは使えず、**Webアプリとしてのデプロイ**と**GeminiRaytechライブラリの追加**が別途必要です。以下、順番に説明します。

## 1. スプレッドシートにApps Scriptを追加する(A・B共通)

1. 学習進捗管理スプレッドシートをGoogleスプレッドシートで開く
2. メニューの「拡張機能」→「Apps Script」を開く(新しいタブでエディタが開きます)
3. 最初から入っている `function myFunction() {}` などのコードを全部削除する
4. このフォルダの `Code.gs` の中身を全部コピーして貼り付ける
5. このフォルダの `appsscript.json` の中身も、エディタ左側の「プロジェクトの設定」(⚙️)で
   「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェックを入れると
   編集できるようになるので、同様に中身を貼り替える(GeminiRaytechライブラリの依存関係が
   含まれているため。手順2でライブラリを追加した場合は上書きしなくてもよい)
6. 上部の保存アイコン(💾)で保存する(プロジェクト名は何でもよい。例:「学習進捗ログ更新」)

## 2. Aの使い方(メニューから手動貼り付け)

保存したら、スプレッドシートのタブに戻り、**一度ページを再読み込み**してください。数秒後、メニューバーに
「**学習進捗ログ**」という新しいメニューが追加されます。これで準備完了です。デプロイ作業は不要です。

初回だけ、メニューの「記録を追加」を押した際に権限の承認画面が出ます。自分のGoogleアカウントで許可してください
(「このアプリは確認されていません」という警告が出ても、自分で作ったスクリプトなので「詳細」→「(プロジェクト名)に
移動」で進めて問題ありません)。

使い方:

1. Claudeに、Zoomの相談会のVTTファイル・企業名・受講者名を渡す
2. Claudeが記録文を作成し、確認を求めてくるので内容をチェックする
3. OKなら、スプレッドシート側で「学習進捗ログ」→「記録を追加」を開く
4. 出てきたダイアログで、企業(シート)と受講者をプルダウンから選び、Claudeが作った文章を「記録内容」欄に貼り付ける
5. 集団相談の場合は「+ 対象者を追加」で行を増やし、参加者ごとに(同じ文章を)企業・受講者を選んで貼り付ける
6. 「この内容で書き込む」を押すと、選んだ受講者の列の一番下に追記される。結果(成功/失敗)がダイアログ内に表示される

## 3. Bの使い方(Webアプリ経由でVTTから自動作成)

### 3-1. GeminiRaytechライブラリを追加する

要約の生成には、個人のGemini APIキーではなく、社内のAI推進室が用意したGASライブラリ
「**GeminiRaytech**」を使う(社内のGemini Gateway移行方針に沿った、GAS向けの正式な接続方法。
APIキーの発行・保管は一切不要)。

1. 利用には所定の権限が必要。**AI推進室(AIチーム)に利用権限の付与を依頼する**
2. Apps Scriptエディタ左側の「ライブラリ」の➕ボタンをクリック
3. スクリプトIDに `1SNn6G_ri9HwMu1jLLoA7ChZVVlS4Vk_LYwUNIWhvBvpYenikR1LrWKcW` を入力して検索
4. バージョンが「2」になっていることを確認して追加
5. ライブラリ欄に「GeminiRaytech」が表示されれば設定完了(詳細・トラブルシューティングは
   社内ドキュメント「GASライブラリ「GeminiRaytech」の使い方」を参照)

### 3-2. 初回権限承認(重要)

Webアプリ経由の初回実行では権限承認のポップアップを出せないため、**先にApps Scriptエディタ側で
手動実行して承認を済ませておく**必要がある。

1. Apps Scriptエディタ上部の関数選択プルダウンで `testGeminiRaytech_` を選ぶ
2. 実行ボタン(▶️)を押す
3. 「承認が必要です」のポップアップが出たら「権限を確認」→ 自分のアカウントを選択 →
   「Googleアカウントへのアクセスを求められる」画面で**全てのチェックボックスにチェックを
   入れて**「続行」
4. 実行ログに何かしらのテキスト(Geminiからの応答)が出ていれば成功

401/403エラーが出る場合は、権限付与(手順3-1の1)が済んでいるか、appsscript.jsonの
`oauthScopes`を独自に上書きしていないかを確認する(詳細は社内ドキュメント参照)。

### 3-3. Webアプリとしてデプロイする

1. Apps Scriptエディタ右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択で「ウェブアプリ」を選ぶ
3. 「次のユーザーとして実行」: **自分**
4. 「アクセスできるユーザー」: **当社内の全員**(「全員」という匿名アクセスの選択肢は会社のWorkspaceポリシー上出てこないが、これで問題ない。使うのは自分だけのため)
5. 「デプロイ」をクリックし、認証を求められたら許可する
6. 発行された **ウェブアプリのURL**(`.../exec` で終わるもの)をブックマークしておく

### 3-4. コードを更新したとき(B利用時のみ重要な注意点)

`Code.gs` の中身を直しても、**保存しただけではWebアプリ側には反映されません**。以下の手順で再デプロイが必要です:

1. 「デプロイ」→「デプロイを管理」
2. 該当のデプロイの鉛筆(編集)アイコンをクリック
3. 「バージョン」を「新バージョン」に変更
4. 「デプロイ」をクリック

(URLは変わらないので、ブックマークはそのままでよい)

### 3-5. 使い方(記録を追加)

Webアプリの上部に「記録を追加」「進捗を確認」の2つのタブがある。まず「記録を追加」タブ:

1. ブックマークしたウェブアプリのURLを開く
2. 集団相談で、対象者があらかじめ「グループ」として保存済みなら、上部の「グループから対象者を
   読み込む」で選んで「このグループを対象者欄に読み込む」を押すと、対象者欄が自動で埋まる
   (手順3を省略できる)
3. 「VTTファイル」を選択し、「実施日」を入力する
4. 「企業(シート)」「受講者」をプルダウンで選ぶ(集団相談の場合は「+ 対象者を追加」で人数分の行を増やす)
5. 「AIで要約を作成」を押す(数十秒かかることがある)。記録内容欄にAIが作った下書きが入る
6. **内容を必ず確認し、必要なら手直しする**(先方企業への報告に使われるため)
7. 「この内容で書き込む」を押すと、選んだ受講者の列に追記される。結果(成功/失敗)が画面下に表示される

### 3-5-2. 使い方(進捗を確認)

「進捗を確認」タブでは、書き込み済みの記録をそのまま閲覧できる(絞り込みながら状況を追う用途):

1. 「企業(シート)」を選び、「この企業の最新状況を一覧」を押すと、その企業の受講者ごとに
   直近1件の記録・記録件数がカードで一覧表示される(先方企業への報告準備に便利)
2. 一覧の中の「全履歴を見る」を押すか、下の「受講者」プルダウンで個別に選んで「この受講者の
   全記録を見る」を押すと、その受講者の全期間分の記録が新しい順(直近が上)に表示される
3. 「表でまとめて見る(PC向け)」を押すと、回数(1回目・2回目...)を縦、受講者を横並びにした
   一覧表で見られる(受講者ごとに実施日はズレていてもよく、各受講者にとっての「何回目の記録か」
   で行を揃えている)。この画面はPCの広い横幅を活かせるよう、進捗確認タブの表示中だけ画面幅を
   広げる作りになっている
4. 一番下の「グループで見る」で保存済みのグループを選び、「このグループの状況を一覧」を押すと、
   企業をまたいだグループのメンバー全員について直近の記録をまとめて確認できる

### 3-5-3. 使い方(登録・管理)

「登録・管理」タブでは、新しい企業・受講者の登録と、集団相談用の「グループ」管理ができる。

**企業・受講者の登録**

1. 「新しい企業名」に企業名を入力し、「企業を登録」を押すとシートが新規作成される
   (この時点では受講者が0人なので、他の画面のプルダウンにはまだ出てこない)
2. 続けて「企業(シート)」で今登録した企業を選び、「新しい受講者名」を入力して
   「受講者を登録」を押す(受講者を1人登録すると、他の画面のプルダウンにも反映される)

**グループ管理(集団相談用)**

同じ組み合わせで繰り返し行う集団相談を「グループ」として保存しておける(企業をまたいでもよい)。

1. 「+ メンバーを追加」で行を増やし、それぞれ企業・受講者をプルダウンで選ぶ
2. 「グループ名」を入力し、「このメンバーでグループを保存」を押す
3. 保存したグループは一覧にカード表示され、「記録追加に使う」を押すと「記録を追加」タブに
   切り替わり、そのグループの全メンバー分の対象者欄が自動で用意される(あとはVTTを選んで
   要約するか、記録内容を直接入力して書き込むだけでよい)
4. 同じ名前で保存し直すとメンバーが上書きされる。「削除」でグループ自体を削除できる

### 3-6. 補足

- 企業(シート)・受講者はVTTの発言者名から自動推定せず、必ず自分でプルダウンから選ぶ仕様にしている(表記ゆれによる誤書き込みを防ぐため)
- 要約が明らかにおかしい場合は、記録内容欄を直接編集してから書き込んでよい
- AとBのどちらを使うかはケースバイケースでよい。Bが使えない・止まっている場合はAにフォールバックできる
- グループの定義は、スプレッドシート内に自動作成される「グループ設定」というシートに保存される。
  直接編集も可能だが、通常はWebアプリの「登録・管理」タブから操作すれば十分(このシートは
  企業・受講者のプルダウンには表示されない)
