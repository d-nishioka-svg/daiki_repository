# GAS Webアプリのデプロイ手順(初回のみ)

`Code.gs` を、学習進捗管理スプレッドシートに紐づけて公開する手順です。一度やれば、以降はURLと合言葉(SECRET)を
Claudeに伝えるだけで使えます。

## 1. スプレッドシートにApps Scriptを追加する

1. 学習進捗管理スプレッドシートをGoogleスプレッドシートで開く
2. メニューの「拡張機能」→「Apps Script」を開く(新しいタブでエディタが開きます)
3. 最初から入っている `function myFunction() {}` などのコードを全部削除する
4. このフォルダの `Code.gs` の中身を全部コピーして貼り付ける
5. 上部の保存アイコン(💾)で保存する(プロジェクト名は何でもよい。例:「学習進捗ログ更新」)

## 2. 合言葉(SECRET)とスプレッドシートIDを設定する

これを設定しないと、書き込みリクエストは全て拒否されます(誰でも書き込めてしまうことを防ぐための鍵です)。

1. Apps Scriptエディタの左側にある歯車アイコン「プロジェクトの設定」を開く
2. 一番下の「スクリプト プロパティ」で「スクリプト プロパティを追加」を2つ作る:
   - `SHEET_ID` : このスプレッドシートのURLで、`https://docs.google.com/spreadsheets/d/` の後、`/edit` の前にある文字列
   - `SECRET` : 好きなランダムな文字列(パスワード)。他人に推測されにくいものにする(例: 20文字程度の英数字)
3. 保存する

## 3. Webアプリとしてデプロイする

1. Apps Scriptエディタ右上の「デプロイ」→「新しいデプロイ」
2. 種類の選択(歯車アイコン)で「ウェブアプリ」を選ぶ
3. 「次のユーザーとして実行」: **自分**(あなたのGoogleアカウント)
4. 「アクセスできるユーザー」: **全員**
   - ここが「全員」になっているとURLを知っていれば誰でもアクセスできてしまいますが、SECRETで守っているので実害はありません。SECRETは他人に教えないでください。
5. 「デプロイ」をクリック
6. 初回は「承認が必要です」という画面が出るので、自分のGoogleアカウントで許可する(「このアプリは Google で確認されていません」という警告が出ますが、自分で作ったスクリプトなので「詳細」→「(プロジェクト名)に移動」で進めて問題ありません)
7. 発行された「ウェブアプリ」のURL(`https://script.google.com/macros/s/.../exec` の形)をコピーする

## 4. ClaudeにURLと合言葉を伝える

このURLと、手順2で決めたSECRETをClaudeに伝えれば準備完了です。

- 毎回伝えるのが面倒な場合、Claude Codeの環境設定で環境変数として登録しておくと、次回以降は聞かれなくなります:
  - `LEARNER_SHEET_WEBAPP_URL` : 手順3-7のURL
  - `LEARNER_SHEET_WEBAPP_SECRET` : 手順2のSECRET

## 5. 動作確認

ターミナルなどで以下を実行し、`"success": true` が返ってくればOKです(実際には書き込みは行われません)。

```bash
curl -s -X POST "<手順3-7のURL>" \
  -H "Content-Type: application/json" \
  -d '{"action":"listStructure","secret":"<SECRET>"}'
```

シート名と受講者名の一覧(`structure`)が返ってくれば、企業シート・受講者列を正しく認識できています。

## コードを更新したいとき

`Code.gs` の中身を直したら、Apps Scriptエディタ側にも同じ内容を貼り直し、「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン→ バージョンを「新バージョン」にして「デプロイ」すればURLは変わらず更新できます。
