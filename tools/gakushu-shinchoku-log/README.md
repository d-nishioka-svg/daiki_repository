# 学習進捗ログ (GAS) — 次回日程一覧 追加

「学習進捗管理スプレッドシート」に紐づくGoogle Apps Scriptプロジェクトのソース。
実体はスプレッドシート側の「拡張機能 → Apps Script」エディタで管理されており、
このリポジトリはコードの変更履歴を追うためのミラーとして置いている
（`clasp`等でのデプロイ連携はしていない。反映は手動でエディタに貼り付ける）。

対象スプレッドシート:
https://docs.google.com/spreadsheets/d/1J689z3a-I1uy-vVaV51VZZ4z9mhzUYUAAC_6F1BXuzE/edit

## このリビジョンで追加した機能: 次回日程一覧

### 背景

各記録の「【次回に向けて】」は自由記述で、次回日程（日付・時刻）もその中に
埋もれてしまっている。POODLE自動登録ツール（`tools/poodle-auto-report/`）など、
他ツールから次回予定を機械的に参照したいというニーズに対し、自由文をパースする
のは表記ゆれが大きく信頼性が低いため、記録時点で次回日程を構造化フィールドとして
別入力してもらう方式にした。

### 変更内容

- 新しい管理シート「**次回日程一覧**」を追加（`グループ設定`と同様、企業一覧には
  出てこない）。列: `企業名 / 受講者 / 次回日付 / 開始 / 終了 / 記録日(今回の相談日) / 更新日時`
- Webアプリ「記録を追加」タブの各対象者行に、**次回相談予定日／開始／終了**の入力欄を追加
  （任意。空のままでもよい。集団相談でも受講者ごとに別々の時刻を入力できる）
- 保存時（`submitEntries` → `appendEntries_`）、次回日程が入力されていれば
  `企業名+受講者名` をキーに「次回日程一覧」へupsert（同じ人の次回予定は上書き）
- 「進捗を確認」タブに「次回日程一覧」の閲覧ボタンを追加（次回日付が早い順、
  日付が既に過ぎている行は「日付経過(未更新の可能性)」バッジを表示）

### 反映手順

1. 対象スプレッドシートを開き、「拡張機能 → Apps Script」でエディタを開く
2. 既存のコードファイルの中身を、この `学習進捗ログ.gs` の内容で置き換える
   （ファイル名はエディタ側の既存名のままでよい。中身だけ差し替え）
3. 保存 → 「デプロイを管理」から既存のWebアプリデプロイを「新バージョン」で更新
   （URLは変わらない）
4. Webアプリを開き、「記録を追加」タブの各行に次回相談予定日欄が出ていることを確認
5. 適当な1件で実際に次回日程を入力して保存し、「進捗を確認」タブの
   「次回日程一覧を見る」で反映されることを確認
   （または、スプレッドシート側に新しくできた「次回日程一覧」シートを直接見てもよい）

### 既知の制約・今後の検討事項

- 次回日程を「未定に戻す」UIは用意していない。誤って入力した場合は
  「次回日程一覧」シートを直接編集（行削除 or 日付欄を空に）すること。
- 複数の企業をまたぐ集団相談の場合、次回日程は受講者ごとの行にそれぞれ入力する
  想定（1つのグループ全体で共有する専用UIは未実装）。
- POODLE自動登録ツール側からこの「次回日程一覧」シートを読む実装は、
  `tools/poodle-auto-report/` 側でまだ行っていない（別途対応が必要）。
